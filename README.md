## What economAIcs is

economAIcs is bid intelligence and compliance software for public transport tendering. It trains an operator's own AI on their own bid history, win themes and evidence, so they win more work and look less like every other bidder. Built natively for the UK Procurement Act 2023, source-cited and audit-logged by design.

Built for bus, rail, ferry, transport technology and transport consulting organisations bidding for public contracts in the UK.
